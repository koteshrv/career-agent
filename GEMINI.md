# CareerAgent System Guidelines

When working on this repository, you must be aware of the custom documentation provided in the `docs/agents/` directory.

Before making significant changes, reading the specific markdown files in `docs/agents/` will help you understand the codebase's existing conventions, patterns, and constraints.

- **Developer Guide**: Refer to `docs/agents/DEVELOPER_GUIDE.md` for comprehensive instructions on modifying the FastAPI Backend, React Frontend, Chrome Extension, and Troubleshooting common errors.
- **System Manual**: Refer to `CAREERAGENT_MANUAL.md` in the root for a high-level system overview, architecture, and every design decision in CareerAgent.
